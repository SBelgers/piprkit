Planned features
================

The features are planned but not yet implemented.

Three-component model
---------------------

Model of the transient, sustained, and persistent component as introduced by Spitschan
et al. (2017) and McAdams et al. (2018).

Blink detection
---------------

Blinks currently need to be provided from an external source; a future feature is blink
detection from the data.

Advanced automatic outlier detection
------------------------------------

Currently a model can be fitted. A future feature is to use this model to automatically determine data quality or outliers.

Automatically stored processing record
--------------------------------------

Automatically record the taken processing steps and data removal, so it is stored alongside the data.
